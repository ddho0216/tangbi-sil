# 초호화 탕비실

브라우저에서 열리는 3D 탕비실 토이 프로젝트 (three.js). 냉장고·냉동실·싱크대·간식 서랍장·과자 자판기·건의사항 게시판을 눌러 보고, 시간이 지나 어질러진 방을 청소합니다.

- 사물을 올리면 이름, 누르면 확대해서 고르기 (큰 팝업 없음)
- 냉장실/냉동실 분리, 음식마다 이름표와 "몇 시간 전" 표시
- 간식 서랍장: 한 번에 한 칸만 열리고 위에서 내려다봄, 5개 미만이면 모의 주문
- 싱크대 설거지/텀블러 씻기, 쓰레기통 비우기, 라면 끓이기 + 젓가락 가르기 미니게임
- 청소 후 6시간 유지, "일부러 어지르기" 버튼
- 1인칭 모드 (WASD), 창문 날씨/테마, 시계로 시간대 변경

## 실행
```bash
npm i three esbuild
bash build.sh   # index.html 생성 → 브라우저로 열기
```
## 참고
- 저장은 localStorage (`tb:` 접두사)
- 과자 사진은 `snack-images.js`에 base64로 넣으면 서랍 속 과자에 입혀집니다 (기본은 직접 그린 임시 그림)
- 기록용 토이 프로젝트입니다
